# Java 自学路线图

> 起点：已独立完成控制台任务管理系统（CRUD + 文件持久化），正在接 SQL Server
> 专业背景：网络工程，大二
> 目标：大二结束前能独立做出"可演示的完整项目"，大三前定下方向

---

## 你现在的位置

```
[✓] Java 基础语法（变量 / 流程控制 / 方法）
[✓] 面向对象（类 / 封装 / 简单分层）
[✓] 集合入门（ArrayList）
[✓] 文件读写（IO 流 + 编码坑）
[→] 数据库连接（JDBC + SQL Server）← 你在这里
[ ] 更远的路……
```

## 阶段一：把现在的项目吃透（本月）

| 任务 | 检验标准 |
|------|---------|
| JDBC 替换 txt 存档 | 增删改查全部走数据库，tasks.txt 退役 |
| 理解 PreparedStatement | 能说出它和字符串拼接比，为什么防 SQL 注入 |
| try-with-resources | 能说出 `try (Connection c = ...) {}` 自动关闭的原理 |
| git 提交习惯 | 一个功能一条 commit，消息写清楚干了啥 |

**学完这一阶段你会拥有**：一个"Java + JDBC + SQL Server"的真实项目，简历可写。

## 阶段二：补基础（寒假，6-8 周）

| 周次 | 内容 | 配套练习 |
|------|------|---------|
| 1-2 | 集合框架全家桶：List/Set/Map、HashMap 原理 | 给项目加"按课程分组统计" |
| 3 | 异常体系：checked vs unchecked、自定义异常 | 项目里去掉 catch(Exception) 大锅饭 |
| 4 | 泛型 | 把 TaskManager 改成泛型类 |
| 5-6 | 多线程基础：Thread、synchronized、线程池 | 概念为主，能聊就行 |
| 7-8 | Lambda + Stream API | 用 Stream 重写任务过滤逻辑 |

**教材**：不用买书，官方教程 + 《Java 核心技术 卷I》当字典查。

## 阶段三：做出"能演示的东西"（下学期）

选一条线深入，别贪多：

**A 线 · 后端开发（走互联网路线）**
```
Spring Boot → RESTful API → 简单前端(Vue) → 部署到 Linux 云服务器
里程碑：一个有登录、有数据库、有公网地址的小系统
```

**B 线 · 网络工程本行（对口你们专业）**
```
Linux 命令行 → 计网实战(Wireshark抓包) → HCIA 认证 → 网络自动化(Netmiko/Ansible, Python)
里程碑：HCIA 证书 + 会写自动化巡检脚本
```

**C 线 · 两条都要（精力允许时）**
Java 是 B 线的加分项（网络自动化也吃编程能力），但主次要分清。

## 每周节奏建议

- **工作日**：每天 1-1.5 小时，写代码 > 看视频（看视频不算学习，敲键盘才算）
- **周末**：一次 3 小时的整块时间，做项目迭代
- **原则**：遇到不懂的概念，先跑通例子再回头理解；卡超过 40 分钟就问 AI 或搜，别硬耗

## 常用资源

| 资源 | 用途 |
|------|------|
| Maven 仓库 (mvnrepository.com) | 找 jar 包依赖（今晚的 JDBC 驱动就来自这） |
| Baeldung (baeldung.com) | Java 各种"怎么做"，例子质量高 |
| LeetCode 简单题 | 阶段二开始，每周 2-3 题，练手感就够 |

## 三条军规

1. **别囤教程**——收藏夹里 10 个教程不如手上 1 个跑通的项目
2. **别跳阶段**——Spring 之前先让 JDBC 裸写熟练，否则出 bug 完全没排查能力
3. **别单人闷头学**——GitHub 提交历史就是你最好的学习记录，坚持推上去
